# CRUD Map: BaCReMS

| Table | C | R | U | D | Pages | Who |
|-------|---|---|---|---|-------|-----|
| resident | ✓ | ✓ | ✓ | – | resident-list, resident-form | Staff: C, R, U. Never deleted, because requests depend on it. |
| certificate_type | ✓ | ✓ | ✓ | – | certificate-types (list + form in one page) | Staff: C, R, U · Resident: R. Not deleted, because requests depend on it. |
| barangay_staff | ✓ | ✓ | ✓ | – | staff-list, staff-form | Staff: C, R, U. Not deleted, because requests keep a record of who handled them. |
| certificate_request | ✓ | ✓ | ✓ | ✓ | request-list, request-form, request-view | Staff: C, R, U (status), D Pending only · Resident: C, R. Approved requests are kept as a record. |
| certificate | ✓ | ✓ | – | – | certificate-view | Staff: C, R · Resident: R. Issued certificates are official records, so they're not edited or deleted. |

## Notes
- Delete is blocked in the database (`ON DELETE RESTRICT`) for resident,
  certificate_type, and barangay_staff when requests exist.

## Form fields: certificate_request

| Column | Form control | Note |
|--------|--------------|------|
| request_id VARCHAR(10) | Read-only text on "Add", hidden field on "Edit" | Generated by the app later. Staff don't type it. |
| resident_id (FK) | `<select>` of resident names | Show the name, store the id |
| certificate_type_id (FK) | `<select>` of certificate names | Show the name, store the id |
| staff_id (FK) | `<select>` of staff names | Required (`NOT NULL`) |
| request_date DATE | `<input type="date">` | Defaults to today |
| purpose_of_request VARCHAR(150) | `<input type="text" maxlength="150">` | Required |
| request_status | `<select>` | Default Pending. Hidden or locked on "Add", shown on "Edit" |
