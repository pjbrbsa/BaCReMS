# CRUD Map: BaCReMS

## 1. CRUD Map

| Table                 |  C  |  R  |  U  |  D  | Pages                                                    | Who                                                                                                                      |
| --------------------- | :-: | :-: | :-: | :-: | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `resident`            |  ✓  |  ✓  |  ✓  |  –  | register, resident-list, resident-view, resident-form    | Resident: C, R, U own profile · Staff: R, U. Never deleted because certificate requests depend on it.                    |
| `certificate_type`    |  ✓  |  ✓  |  ✓  |  –  | certificate-types (list + form in one page)              | Staff: C, R, U · Resident: R. Not deleted because existing requests depend on it.                                        |
| `barangay_staff`      |  ✓  |  ✓  |  ✓  |  –  | staff-list, staff-form                                   | Staff: C, R, U. Not deleted because requests keep a record of who handled them.                                          |
| `certificate_request` |  ✓  |  ✓  |  ✓  |  ✓  | request-list, request-form, request-view                 | Resident: C, R own requests · Staff: R, U status, D pending only. Approved requests are kept as records.                 |
| `certificate`         |  ✓  |  ✓  |  –  |  –  | certificate-list, certificate-view, certificate-generate | Staff: C, R · Resident: R own certificates. Issued certificates are official records, so they are not edited or deleted. |

**Legend:**

- C – Create (Add new records)
- R – Read (View existing records)
- U – Update (Edit existing records)
- D – Delete (Remove records)
                           
## 2. Form fields: certificate_request

| Column | Form control | Note |
|--------|--------------|------|
| request_id VARCHAR(10) | Read-only text on "Add", hidden field on "Edit" | Generated by the app later. Staff don't type it. |
| resident_id (FK) | `<select>` of resident names | Show the name, store the id |
| certificate_type_id (FK) | `<select>` of certificate names | Show the name, store the id |
| staff_id (FK) | `<select>` of staff names | Required (`NOT NULL`) |
| request_date DATE | `<input type="date">` | Defaults to today |
| purpose_of_request VARCHAR(150) | `<input type="text" maxlength="150">` | Required |
| request_status | `<select>` | Default Pending. Hidden or locked on "Add", shown on "Edit" |
